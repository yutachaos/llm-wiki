# Ingest

引数: 取り込むソースのファイルパスまたは URL。

CLAUDE.md のスキーマに従って以下を実行する。

## 手順

1. **ソースの保存**
   - URL の場合: 内容を取得し、`sources/<slug>.md` に保存する。冒頭に取得元 URL と取得日を記載する
   - ファイルパスの場合: `sources/` にコピーする（元の形式のまま）
   - slug は内容を表す kebab-case の英語。既存ソースと重複していないか `sources/` と `wiki/index.md` を確認し、重複ならユーザーに報告して中断する
2. **ソース要約ページの作成**
   - ソースを読み、`wiki/sources/<slug>.md` に要約ページを作成する（frontmatter 必須、`type: source`）
   - 要点・主張・重要な引用を日本語でまとめる
3. **wiki への統合（このスキルの本体）**
   - `wiki/index.md` から関連する既存の topic / entity ページを特定し、すべて読む
   - 新情報を既存ページに**統合**する。新規ページの作成は、既存ページに収まらない概念・エンティティの場合のみ
   - 関連ページ間に相対 markdown リンクを双方向に張る
   - 既存の記述と矛盾する情報があれば、上書きせず「## 矛盾」セクションに両論併記し出典を明記する
4. **ブックキーピング**
   - 作成・更新したページを `wiki/index.md` に反映する
   - `wiki/log.md` に本日の日付でエントリを追記する（取り込んだソース、作成・更新したページ）
5. **報告**
   - 取り込んだソース、作成・更新したページの一覧、統合時の判断（新規作成した理由、矛盾の有無）をユーザーに報告する

## 禁止事項

- `sources/` 内の既存ファイルの編集・削除
- `wiki/log.md` の過去エントリの変更
