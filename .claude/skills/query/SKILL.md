# Query

引数: 質問。

## 手順

1. `wiki/index.md` を読み、質問に関連するページを特定して読む。ページ内のリンクも必要に応じて辿る
2. **wiki の内容から**回答を合成する。根拠としたページを相対リンクで引用する
3. wiki に十分な情報がない場合:
   - 「wiki 未収載」であることを明示する
   - 必要なら `sources/` の生ソースにフォールバックして回答を補う（その場合はソース由来であることを明示する）
4. 回答の過程で wiki の欠落・陳腐化・矛盾に気づいたら、回答の最後に指摘する。**このスキルでは wiki を編集しない**（修正は /lint または /ingest で行う）

## 禁止事項

- wiki・sources への一切の書き込み
- wiki にもソースにもない情報を、出典があるかのように答えること（一般知識で補う場合はその旨を明示する）
