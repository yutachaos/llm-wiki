# Lint

引数: なし。

## 手順

1. **機械的チェック**（`wiki/` 全ページを対象）
   - リンク切れ: 相対リンクの参照先ファイルが存在するか
   - 孤立ページ: `wiki/index.md` に載っていないページ
   - 幽霊エントリ: `wiki/index.md` にあるが実体ファイルがないもの
   - frontmatter 不備: `title` / `type` / `sources` / `updated` の欠落、`sources` が指すファイルの不存在
   - 重複ページ: 同じ概念を扱うページが複数ないか。ファイル名スラッグの類似（`okr` / `objectives-and-key-results` のような表記違い）と、`title` / `# 見出し` / 出典行の重なりで判定する。検出したら統合を提案する（どちらかを消すのでなく1ページにまとめ、リンク元の表記も揃える）
2. **内容チェック**
   - **数値の原文照合**: 各ページの数値・割合・金額・年号を抽出し、frontmatter の `sources` が指す `sources/` の原文に当該の値が存在するか照合する。原文にない数値は要約中に生成された可能性が高いので削除するか「未検証」と明示する。`sources` を持たないページ（モデル知識由来）は照合できないため、数値を含むものを一覧で報告する
   - ページ間の矛盾（「## 矛盾」セクションで管理されていない不整合）
   - 相互リンク漏れ: 内容が関連しているのに片方向・未リンクのページ
   - 陳腐化: ソースに対して要約・統合が古くなっているページ
3. **レポート**
   - 検出結果を「問題 → 修正案」の一覧としてユーザーに提示する
   - 問題がなければ「問題なし」と報告して終了
4. **修正**
   - ユーザーの承認を得てから修正を適用する
   - 修正内容を `wiki/log.md` に追記する（`lint:` プレフィックス）

## 禁止事項

- 承認前の修正適用
- `sources/` の変更（ソース側の問題は指摘にとどめる）
