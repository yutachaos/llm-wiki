# SPACE framework と DX Core 4

- 出典: [getdx.com の DX Core 4 紹介ページ](../../sources/dx-core-4-space-framework.md)ほか

## 要点

### SPACE framework

開発者生産性を5次元（Satisfaction, Performance, Activity, Communication & collaboration, Efficiency & flow）で捉える広範なフレームワーク。ただしカテゴリを提示するのみで、各次元で具体的に何を測るべきかまでは定義しない。そのため多くのチームが自前でメトリクスを定義することの難しさから、1四半期以内にSPACEの運用を放棄したとされる。

### DX Core 4

DORA・SPACE・DevExを統合し、開発者生産性を測る単一のフレームワークとして DX社（Laura Tacho・Abi Nodaら、DORA/SPACE/DevExの著者であるNicole Forsgren・Margaret-Anne Storey・Thomas Zimmermanらの協力）が開発。4次元で構成される:

- **Speed**: コード変更をどれだけ速く届けられるか（PR数/エンジニア、リードタイム、デプロイ頻度など）
- **Effectiveness**: （開発者体験・フロー効率に関する次元）
- **Quality**: 本番の安定性・信頼性
- **Impact**: コードを書く以上にビジネス価値へどれだけ貢献しているか

「単なる定義の統一」に留まらず、他組織とのベンチマーク比較、組織全体〜チームレベルへのドリルダウン、インプットとアウトプット双方の可視化を狙う。ある顧客は「エンジニアリング組織の血液検査やCTスキャンを受けるようなもの」と評している。
