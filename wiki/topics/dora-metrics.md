# DORAメトリクス（Four Keys）

- 提唱者: ニコール・フォースグレン、ジェズ・ハンブル、ジーン・キム
- 分野: ソフトウェアデリバリー・組織パフォーマンス
- 出典: 『LeanとDevOpsの科学』(Accelerate, 2018)、DORA State of DevOps Report

## 概要

数万組織の調査から、ソフトウェアデリバリーのパフォーマンスを測る4指標を統計的に導出し、それが組織全体の業績と相関することを示した研究。「速度と安定性はトレードオフではなく両立する」が最重要の発見。

## 主要概念

| 指標 | 測るもの |
|---|---|
| デプロイ頻度 | 本番リリースの頻度（速度） |
| 変更のリードタイム | commit から本番稼働まで（速度） |
| 変更障害率 | デプロイが障害を起こす割合（安定性） |
| サービス復元時間 (MTTR) | 障害からの復旧時間（安定性） |

- ハイパフォーマーは4指標すべてで優れる。速度を上げると安定性も上がる（バッチが小さくなるため）
- 指標を改善する能力（ケイパビリティ）も特定されている: 継続的デリバリー、疎結合アーキテクチャ、Westrum の創造的組織文化、学習文化など
- 指標は目標でなく健康診断。目標化すると Goodhart の法則で歪む（デプロイ頻度のために空デプロイ等）

## マネジメントへの適用

- 「品質のためにリリースを減らす」という直観への反証データとして使える
- 4指標が悪いとき、原因は大抵プロセスやアーキテクチャ（デプロイ手順の手作業、密結合）。個人の頑張りで改善させない
- チーム間比較でなく、同一チームの時系列変化を見る
