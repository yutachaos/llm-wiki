# Westrum の組織文化類型

- 提唱者: ロン・ウェストラム
- 分野: 組織文化・安全工学
- 出典: Westrum "A typology of organisational cultures" (BMJ Quality & Safety, 2004)、[『LeanとDevOpsの科学』(Accelerate, 2018)](dora-metrics.md)

## 概要

組織の情報の流れ方（information flow）で文化を3類型に分けるモデル。もともと航空・医療の安全研究から出たもので、[DORAメトリクス](dora-metrics.md)の研究がデリバリーパフォーマンスを予測するケイパビリティとして「創造的（generative）文化」を採用したことでソフトウェア業界に広まった。組織文化を「価値観の標語」ではなく**情報が流れるかどうか**という観測可能な行動で測る点が実務上の要点。

## 主要概念

| 類型 | 志向 | 情報の扱い |
|---|---|---|
| 病的 (Pathological) | 権力志向 | 情報は個人の権力のために隠される・歪められる |
| 官僚的 (Bureaucratic) | ルール志向 | 情報は所定の経路を通り、部門の縄張りを越えない |
| 創造的 (Generative) | パフォーマンス志向 | 情報は使う人に届くよう積極的に流される |

6つの観測軸（上から病的 / 官僚的 / 創造的の順）:

- **協力**: 低い / 中程度 / 高い
- **悪い知らせの伝達者**: 撃たれる / 無視される / 訓練される
- **責任**: 回避される / 細分化される / 共有される
- **部門間の橋渡し**: 妨げられる / 許容される / 報われる
- **失敗**: スケープゴート探し / 裁き（正義の追求） / 探究（inquiry）
- **新しいアイデア**: 潰される / 問題視される / 実行される

- 「悪い知らせの伝達者がどう扱われるか」が最も鋭い診断指標。ここが撃たれる文化では、他の制度をいくら整えても情報が上がらない
- [心理的安全性](psychological-safety.md)はチームレベルの現象、Westrum の類型は組織レベルの情報流通。両者は相互に補強する

## マネジメントへの適用

- 文化を変えたいときは標語でなく上記6軸の具体的な行動を変える。特に「悪い知らせを持ってきた人がどうなったか」の実例が組織に記憶される
- blameless postmortem は「失敗＝探究」への移行の実装。犯人探しの制度（責任者の明示要求など）と併存させると病的側に引き戻される
- 官僚的文化は病的よりはマシだが、情報が部門境界を越えないため[コンウェイの法則](conways-law.md)的な調整コストが慢性化する。橋渡し行動を評価対象にする
